# Telegram Media Downloader Bot (Production Ready)

بوت تيليجرام احترافي عربي متخصص في تنزيل الوسائط من أشهر المنصات، مبني بتقنيات حديثة وجاهز للإنتاج.

## المميزات الرئيسية

### المنصات المدعومة
- **Instagram**: Reels, Posts, Stories, Carousel
- **TikTok**: فيديوهات بدون علامة مائية
- **YouTube**: جميع الدقات (144p - 4K) + استخراج MP3
- **X (Twitter)**: فيديوهات وصور
- **SoundCloud**: تنزيل MP3 مع معلومات المقطع
- **Pinterest**: فيديوهات وصور

### نظام الاشتراك الإجباري
- دعم قناة واحدة أو عدة قنوات
- التحقق التلقائي من الاشتراك
- منع الاستخدام قبل الاشتراك
- إدارة سهلة للقنوات

### لوحة التحكم الإدارية
- إحصائيات شاملة (المستخدمين، التحميلات، المنصات)
- نظام حظر وإلغاء حظر
- إذاعة رسائل لجميع المستخدمين
- إدارة القنوات الإجبارية

### الحماية والأمان
- حماية من السبام (Rate Limiting)
- منع الطلبات المتكررة
- التحقق من صحة الروابط
- معالجة الأخطاء بشكل احترافي

## المتطلبات

### متغيرات البيئة المطلوبة
```env
BOT_TOKEN=your_bot_token_from_botfather
DATABASE_URL=postgresql://user:password@host:port/database
ADMIN_IDS=123456789,987654321
```

### التقنيات المستخدمة
- **Node.js**: بيئة التشغيل
- **PostgreSQL**: قاعدة البيانات
- **Telegram Bot API**: واجهة التيليجرام
- **Cobalt Tools API**: استخراج الوسائط

## التثبيت والتشغيل

### 1. إعداد البوت في تيليجرام
1. تحدث مع @BotFather
2. أنشئ بوت جديد باستخدام /newbot
3. احفظ الـ Token الذي سيعطيك إياه

### 2. إعداد قاعدة البيانات
قاعدة البيانات تم إنشاؤها تلقائياً وتحتوي على:
- جدول users: المستخدمين
- جدول downloads: سجل التحميلات
- جدول force_subs: القنوات الإجبارية
- جدول settings: الإعدادات العامة

### 3. تعيين متغيرات البيئة
قم بإضافة المتغيرات التالية في إعدادات المشروع:
- BOT_TOKEN: توكن البوت
- ADMIN_IDS: معرفات المسؤولين (مفصولة بفواصل)
- DATABASE_URL: رابط قاعدة البيانات (موجود تلقائياً)

### 4. تفعيل الـ Webhook
بعد نشر المشروع، قم بتعيين الـ Webhook:

```bash
curl -X POST "https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=https://your-domain.com/api/bot"
```

أو قم بزيارة:
```
https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=https://your-domain.com/api/bot
```

### 5. التحقق من الـ Webhook
للتحقق من حالة الـ Webhook:
```bash
curl "https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getWebhookInfo"
```

## الأوامر المتاحة

### أوامر المستخدمين
- /start - بدء البوت وعرض رسالة الترحيب

### أوامر المسؤولين

#### الإحصائيات
```
/admin
/stats
```
عرض إحصائيات شاملة عن البوت

#### إدارة القنوات الإجبارية
```
/forcesubs
```
عرض قائمة القنوات الإجبارية الحالية

```
/setforce [معرف_القناة] [اسم_القناة] [رابط_الدعوة]
```
إضافة قناة إلى قائمة الاشتراك الإجباري

مثال:
```
/setforce -1001234567890 قناتي https://t.me/mychannel
```

```
/removeforce [معرف_القناة]
```
إزالة قناة من قائمة الاشتراك الإجباري

#### إدارة المستخدمين
```
/ban [معرف_المستخدم]
```
حظر مستخدم من استخدام البوت

```
/unban [معرف_المستخدم]
```
إلغاء حظر مستخدم

#### الإذاعة
```
/broadcast [الرسالة]
```
إرسال رسالة لجميع المستخدمين

مثال:
```
/broadcast مرحباً! تم تحديث البوت بميزات جديدة
```

## الإعدادات المتقدمة

### حدود الاستخدام (Rate Limits)
يمكنك تعديل حدود الاستخدام في config.js:
```javascript
rateLimits: {
  maxRequestsPerMinute: 10,
  maxRequestsPerHour: 100,
  cooldownSeconds: 3
}
```

### إعدادات التحميل
```javascript
download: {
  maxFileSize: 50 * 1024 * 1024, // 50 MB
  timeout: 120000, // 2 دقيقة
  retries: 3
}
```

## استكشاف الأخطاء

### البوت لا يستجيب
1. تحقق من أن الـ Webhook مفعل بشكل صحيح
2. تأكد من أن BOT_TOKEN صحيح
3. راجع سجلات الأخطاء في لوحة التحكم

### فشل التحميل
1. تأكد من أن الرابط عام وليس خاص
2. بعض المنصات قد تحظر الطلبات الآلية
3. تحقق من حجم الملف (الحد الأقصى 50 ميجابايت)

### مشاكل الاشتراك الإجباري
1. تأكد من أن معرف القناة صحيح (يبدأ بـ -100)
2. تأكد من أن البوت مسؤول في القناة
3. تحقق من أن رابط الدعوة صحيح

## قاعدة البيانات

### جدول المستخدمين (users)
```sql
- id: معرف تلقائي
- telegram_id: معرف التيليجرام (فريد)
- username: اسم المستخدم
- full_name: الاسم الكامل
- language_code: لغة المستخدم
- is_banned: حالة الحظر
- created_at: تاريخ التسجيل
```

### جدول التحميلات (downloads)
```sql
- id: معرف تلقائي
- user_id: معرف المستخدم
- platform: المنصة (instagram, tiktok, etc.)
- url: الرابط المحمل
- created_at: تاريخ التحميل
```

### جدول القنوات الإجبارية (force_subs)
```sql
- id: معرف تلقائي
- channel_id: معرف القناة (فريد)
- channel_title: اسم القناة
- invite_link: رابط الدعوة
- created_at: تاريخ الإضافة
```
